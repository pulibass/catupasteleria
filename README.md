# Catú Pastelería · Carta digital

Carta digital responsive de Catú Pastelería, con panel protegido para actualizar productos, precios, dirección, horarios, Instagram y editores autorizados.

## Desarrollo local

```bash
npm install
npm run db:generate
npm run build
npm run dev
```

El sitio usa una base D1 para conservar los cambios realizados desde el panel.
